# Real Estate Full Stack Project

A full stack real estate web application where users can browse properties, view details, and contact agents.

## 🚀 Tech Stack

Frontend
- React.js
- CSS
- JavaScript

Backend
- Python
- Django
- Django REST Framework

Database
- SQLite

## ✨ Features

- User Login & Registration
- Property Listings
- Residential & Commercial Properties
- Property Details Page
- Contact Form
- Blog Section
